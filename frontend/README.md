# sensei-sql frontend

React + TypeScript + Vite + Tailwind v4 + [shadcn/ui](https://ui.shadcn.com) (Base UI primitives) + Recharts.
Two pages:

- **Assistant** (`/`): pick a Spider database or upload a SQLite file, ask in plain English, edit and re-run the SQL,
  see the result table and a session history. Talks to the Python server (`src/sensei_sql/app/api.py`) over `/api/*`.
- **Results** (`/results`): the project's numbers, charts and ablations. Static: it reads
  `src/content/results.json`, which is generated by `python scripts/export_results.py` (`make frontend-data`) from the
  evaluation outputs and committed, so the page builds without those outputs.

```bash
make frontend                 # npm ci && npm run build  -> frontend/dist (served by the python app)
make app                      # python -m sensei_sql.app, serves the API and frontend/dist on :7860

# development with hot reload (the python app must be running for /api)
cd frontend && npm install && npm run dev      # http://127.0.0.1:5173, proxies /api to :7860
```

Everything is bundled (fonts included): nothing is loaded from the network at run time.
Components in `src/components/ui/` come from the shadcn CLI (`npx shadcn@latest add <name>`).
